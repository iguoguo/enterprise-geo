# cases/（脱敏落地案例）

本目录用于存放**已脱敏**、并获得客户授权的 GEO 落地案例。

## 当前状态
- 结合同的具体客户案例（医院 / 制造 / 商贸等）涉及客户保密信息，**尚未脱敏放行**，暂不公开入库。
- 公开统一口径示例（不指名客户）：

> 我们用 enterprise-geo skill 为一家东北专科医院做 GEO：先做 A0 基础检查与阶段 A 现状诊断，建医疗合规知识底座（病种/就诊/费用等口径），产出结论前置的权威 FAQ 与分发台账，显著提升品牌信息在主流 AI 引擎中的触达与占位。

## 使用约束
- 仅收录已获客户书面授权的脱敏内容；
- 隐去客户全称、关键可识别信息与内部数据；
- 结果数据只给方向性表述，不给可对标的原始值。
