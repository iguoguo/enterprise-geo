## 主要功能

- **A0 前置基础检查**：备案 / HTTPS / robots / sitemap / 首页 meta / 官网身份是否被 AI 认对——避免做无效优化。
- **现状诊断**：品牌词/核心词/长尾/竞品/行业五类探测集，≥2 引擎采样，算「可见度 / 占位率 / 引用率 / 来源可用率 / 负面覆盖度」五维基线。
- **受众与关键词策略**：决策链画像 + 三层关键词语义地图 + 内容目标分配表 + 术语表。
- **知识底座**：沉淀「可追溯、口径一致、组织良好」的单一事实源。
- **内容生产**：结论前置、可扫描、有出处、口径统一，带审核闸口。
- **多渠道分发 / 度量治理 / 反馈回流**：把「业绩靠内容、内容靠知识、知识靠回流」跑成闭环。

## 八阶段流程

```
A0. 基础检查  A. 现状诊断   B. 受众与关键词策略   C. 知识底座   D. 内容生产
E. 多渠道分发 F. 度量与治理           G. 反馈回流与迭代
G ←── 回流（事实/口径/选题/数据）─────┘
```
