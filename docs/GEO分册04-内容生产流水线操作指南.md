# 分册04｜内容生产流水线操作指南

> 配套《企业 GEO 优化架构性方案》第六章「第三层：内容生产层」
> 定位：把"蒸馏 → 生成 → 审核 → 落位 → 优化 → 纳入回流体系"跑成一条可重复、可批量、有验证的生产线。

---

## 一、核心工作流

```
① 选题（来自关键词地图/覆盖缺口）
   │
② 蒸馏（从知识底座抽素材，保留出处）
   │
③ 生成（按作者人设 + 术语表+ 提示词）
   │
④ 审核（事实/口径/合规/格式）  ←─ 必过，绝不放行错误
   │
⑤ 落位（发布到官网/渠道，附来源）
   │
⑥ 优化（据反馈/度量迭代，纳入回流）
   └──────── 回流更新知识底座（新事实/勘误）
```

> 与主方案六步（蒸馏-选词-人设-生成-优化发布-回流）对齐。

---

## 二、步骤 1：选题管理

- 来源：来自分册01 的**覆盖缺口**、分册02 的**目标分配表**、实体反馈（客服、销售、评论区高频问题）。
- 建**选题积压表**，字段：标题、目标词、主题域、受众角色、内容形态、优先级、状态。
- 按"内容目标"决定形态（权威综述/对比/案例/FAQ/白皮书）。

---

## 三、步骤 2：知识蒸馏（保真与溯源）

- 从知识底座按"目标词→主题域→关联条目"抽取**素材包**。
- 素材包必须带**出处/版本**，确保生成的每一句关键事实都可反查。
- 提炼时保持口径一致；临时补充的外部事实要另列来源，不混入底座结论。

**蒸馏提示词示例（面向生成）**：
```
基于知识底座中「工业质检相机」主题的相关条目，为其内容生成提供素材，
逐条列出：事实 / 出处 / 版本 / 可引用的关键数据。缺失的知识点在备注中标出。
```

---

## 四、步骤 3：内容生成（人设 + 提示词约束）

### 4.1 以作者人设起草
选受众对应作者人设，生成"以目标读者口吻可懂、专业级"的内容摘要起草，再正式成文。

### 4.2 面向 GEO 的生成约束（六要素）
1. **结论优先/可扫描**：标题与小标题直接给结论与关键词。
2. **覆盖提问句式**：把"怎么选/多少钱/和XX比/多久交付/有案例吗"等句式纳入正文结构。
3. **引用与出处**：关键数据给出处/链接/日期，方便生成引擎采信。
4. **结构化**：用标题层级 + 列表 + FAQ 块，利于抽取。
5. **无夸大无失实**：严格遵守术语表与口径。
6. **可追溯**：留存"基于哪些素材生成"的记录。

---

## 五、步骤 4：审核关卡（强制）

任一内容上线前过以下闸口，任一不满足即驳回修改：

| 审核维度 | 标准 | 
|----------|------|
| 事实准确性 | 与知识底座一致，数据可溯源 |
| 口径一致性 | 符合品牌术语表，无"同实异述" |
| 合规性 | 无广告法违禁词、无夸大、涉密不泄露 |
| 结构可读 | 结论前置、正文可扫描、FAQ 成块 |
| 唯一性 | 不与既有内容重复 |

> 建立审核人角色与流程；AI 生成稿仅视为草稿，人审为必需环节。

---

## 六、步骤 5：落位发布

- 按分发分册的渠道矩阵发布。
- 官网内容同步到官网技术分册的规范（结构化/权威页/FAQ/Schema）。
- 发布时记录：URL、发布时间、作者、目标词、版本。

---

## 七、步骤 6：优化与回流

- 定期从度量数据取反馈（曝光、占位、转化、问答命中）调优选题与措辞。
- 事实变更、勘误 → **回流到知识底座**更新，保证下次生成用的是新口径。
- 建立"内容-知识"双写机制：内容生产既是消费知识的过程，也是沉淀新知识的过程（用户答疑产生的真问题）。

---

## 八、批量生产能力（放量）

- 用「选题积压表 + 作者人设 + 术语表 + 提示词模板」批量生成初稿，降低人审压力前提下放大产量。
- 批量时保留每篇的"素材出处记录"，便于追溯与抽查。
- 数量与质量平衡：优先覆盖高价值缺口词，不与低质刷量混淆。

---

## 九、GEO 内容质量自检清单

- [ ] 标题/小标题含目标关键词，结论在前
- [ ] 覆盖目标提问句式，段落可扫描
- [ ] 每一关键数据有出处/链接/日期
- [ ] 符合品牌术语表，无夸大
- [ ] 结构含列表与 FAQ 块，利于抽取
- [ ] 与既有没有重复
- [ ] 通过审核四闸口
- [ ] 已记录发布 URL，且已纳入回流监控
