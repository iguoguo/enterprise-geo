# 分册01｜企业 GEO 现状诊断操作指南

> 配套《企业 GEO 优化架构性方案》第二章
> 定位：把"量出企业当下在生成式引擎里的位置"这一第 0 步，拆成可照着执行的操作手册。

---

## 一、本分册要解决的问题

在投入资源建体系之前，"诊断"先回答三件事：
1. 企业现在在 AI 引擎里**是什么位置**（被看见多少、被怎么评价）；
2. 相比竞品/行业基线**差在哪**；
3. 优化的**缺口与优先级**在哪。

产出物：一份《企业 GEO 现状基线报告》，成为后续所有分册的起点与度量层"改善了多少"的对照基准。

---

## 二、诊断全流程图

```
① 建探测集 ──▶ ② 批量采样 ──▶ ③ 结构化统计
                                        │
④ 官网/来源核查 ◀──┬── ⑤ 竞品对标 ◀─────┤
                                        ▼
                  ⑥ 口径与失实排查 ──▶ ⑦ 综合成报告（基线 + 缺口 + 优先级）
                                        ▼
                  分发驱动：战略·关键词 / 知识底座 / 内容分发 / 度量基线
```

---

## 三、步骤 1：搭建探测集（地基）

探测集决定"测什么"，是诊断质量的关键。

### 3.1 关键词库准备
- 从企业主营产品/服务提炼**核心词**（如"工业质检相机"）。
- 从这些词展开**长尾疑问**（"工业质检相机怎么选""钢表面缺陷检测用什么"）。
- 补充**品牌词**（企业名、产品名、简称）、**竞品词**、**行业词**。

**示例探测词表（模板）**：

| 类型 | 示例词 | 用途 |
|------|--------|------|
| 品牌词 | 华工智造、CAM-1000 | 测品牌被提及 |
| 核心词 | 工业质检相机、智能质检方案 | 测占位与竞争 |
| 长尾疑问 | 质检相机怎么选、金属表面缺陷如何检测 | 测长尾覆盖 |
| 竞品词 | XX检测、YY视觉 | 竞品对标 |
| 行业词 | 产线自动化、机器视觉检测 | 测行业站位 |

### 3.2 提问句式（Prompt 集）
对每个词组织成**标准提问句式**，保证结果可比：
- 直接点名式：`推荐一款工业质检相机`
- 选型式：`工业质检相机怎么选？`
- 对比式：`华工智造和XX比，智能质检哪个好`
- 解决式：`钢表面缺陷检测用什么设备`
- 品牌查询式：`华工智造是做什么的`

### 3.3 探测集结构化
将"词 × 句式 × 引擎"组织成一个可枚举清单，格式：

```json
{
  "engines": ["豆包", "DeepSeek", "文心一言", "通义千问"],
  "items": [
    {"id": 1, "question": "推荐一款工业质检相机", "kwType": "核心词"},
    {"id": 2, "question": "工业质检相机怎么选？", "kwType": "长尾"}
  ]
}
```

## 四、步骤 2：批量采样（收集）

### 4.1 采样方式
- **优先自动化**：用脚本/工具对「探测集」逐条向各生成引擎发起提问并记录回答（建议同一天内完成一轮，避免口径漂移）。
- **无自动化时人工抽样**：抽取代表性词条（每个词类型至少 3–5 条）人工检索并记录。

### 4.2 单条记录格式（评分表）

| 字段 | 记录内容 |
|------|----------|
| 引擎/词条/句式 | 采样对象标识 |
| 是否提及 | 是/否 |
| 占位等级 | 被推荐 / 并列提及 / 仅出现 / 不出现 |
| 情感倾向 | 正面 / 中性 / 负面 |
| 是否带来源 | 是/否；来源 URL 记录 |
| 来源是否指向官网 | 是/否 |
| 内容准确性 | 准确 / 部分失实 / 严重失实（记录原文） |

（可用表格或脚本批量落库，便于后续统计）

---

## 五、步骤 3：结构化统计（算基线）

对采样结果计算以下指标（即第二章 2.4 的基线清单）：

| 指标（记法） | 计算 | 含义 |
|------|------|------|
| 可见度 V | 被提及条数 ÷ 总条数 | 是否被看见 |
| 占位率 P | 被"推荐/并列"条数 ÷ 总条数 | 是否被信任优先 |
| 引用率 | 带可溯源来源条数 ÷ 被引用条数 | 是否可持续被采用 |
| 来源可用率 | 来源可打开且指向官网/权威的条数 ÷ 带来源条数 | 来源基建是否扎实 |
| 负面覆盖度 | 负面/失实条数 ÷ 总条数 | 声誉风险水位 |
| 覆盖缺口 | 应占位却未占位的关键词数 | 内容机会与发力点 |

> 建议把结果落成一张**可视化基线表**（每引擎一行、每指标一列），作为改善前后对照。

---

## 六、步骤 4：官网/来源侧核查（查地基）

- 用站内抓取工具核查：关键页是否被收录、有无深埋/孤儿页、Sitemap 是否完整、结构化数据是否有误。
- 检查"当前被引用时来源指向哪"：哪些第三方在为企业在 AI 中背书，来源质量如何。
- 落到第二章官网清单（可抓取/可理解/可信任/可消费/面向 Agent）。

---

## 七、步骤 5：竞品与基线对标（定差距）

- 对主要竞品跑**同一个探测集**。
- 对比项：可见度、占位率、被推荐频次、覆盖词数。
- 产出：差距矩阵，明确"最大机会点"（如竞品占位但企业零占位的核心词）。

---

## 八、步骤 6：口径与失实排查（防风险）

- 逐条核查 AI 输出中与本企业相关的：事实、数据、历史、表述。
- 标记需澄清/纠偏的点：失实事实（需建澄清内容）、过时信息、负面表述。
- 这些清单直接转给"内容生产/官网纠偏"分册作为第一批任务。

---

## 九、步骤 7：合成基线报告

《企业 GEO 现状基线报告》应包含：
1. **现状画像**：一张五维基线表 + 说明。
2. **差值清单**：对竞品/基线的差距与机会点。
3. **覆盖缺口矩阵**：词 → 缺口 → 优先级。
4. **负面/失实清单**：需澄清与修正项。
5. **官网/来源体检结果**：地基健康度。
6. **优化优先级建议**：按"见效速度 × 投入"排布。

**报告分发定位**：
- 战略·关键词分册 → 校准关键词与目标；
- 知识底座分册 → 优先补缺与溯源；
- 内容/分发分册 → 生成第一批选题与纠偏内容；
- 度量治理分册 → 以此基线为对比基准。

## 十、诊断执行检查清单

- [ ] 探测集覆盖：品牌/核心/长尾/竞品/行业五类词
- [ ] 标准提问句式就绪，可比
- [ ] 覆盖 ≥2 个主流生成引擎
- [ ] 采样同批完成，避免口径漂移
- [ ] 五维基线指标计算完成
- [ ] 官网/来源检查完成
- [ ] 竞品对标跑完同一探测集
- [ ] 负面/失实清单已列出
- [ ] 基线报告成文并分发到各分册

---

*一个企业通常 1–2 周可完成首轮诊断；其价值在于"一次测准、长期对标"。*
