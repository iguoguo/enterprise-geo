# 分册03｜知识底座建设操作指南

> 配套《企业 GEO 优化架构性方案》第五章「第二层：数据与知识底座」
> 定位：把"散落资料"沉淀为"可追溯、口径一致、组织良好"的 GEO 事实底座——内容与知识的源头。

---

## 一、目标与产出

核心产出：
1. **文档树**：把可沉淀资料归并成有组织的目录结构；
2. **知识图谱**：条目化的知识 + 层级 + 关联 + 来源；
3. **来源与版本规范**：事实可追溯、可反查、可审计；
4. **单一事实源 + 术语表对齐**：杜绝口径漂移。

> 说明：知识提取与组织在 2Ryun 等平台可自动完成，这里聚焦"哪些内容入库、如何保证质量与一致性"的操作。

---

## 二、步骤 1：资料盘点与分类（清家底）

### 1.1 盘点范围
- 散落文件：白皮书、章程、产品手册、案例、FAQ、历史内容、培训资料、政策/资质文件。
- 可复用：官方口径、规范、对外已发布内容。
- 按需清理：过时、重复、口径冲突、涉密（独立管控不进公开底座）。

### 1.2 判断哪些该进入知识底座
| 内容 | 是否入底座 | 原因 |
|------|-----------|------|
| 用户原创/一手事实/经验 | ✅ 入 | 新知识 |
| 外部参考资料/报告 | ✅ 入 | 可溯源素材 |
| 根据底座衍生的总结/报告 | ❌ 不入 | 既有知识的重组，浪费算力 |
| 会议/随手草稿未定稿 | ❌ 暂不入 | 待整理，可先放笔记 |
| 涉密/未公开 | ❌ 不入公开底座 | 隐私合规 |

### 1.3 建文档树（目录骨架）
规划统一目录，例如：
```
知识底座
 ├─ 01 企业概况（介绍/历程/资质）
 ├─ 02 产品（各产品线/型号/参数）
 ├─ 03 解决方案（场景/选型/实施）
 ├─ 04 案例（行业/客户/量化成果）
 ├─ 05 技术知识（原理/常见问题/白皮书）
 ├─ 06 官方口径与术语表
 └─ 07 合规与政策文档（按需分权）
```
> 用文档树把资料组织成"有层级、有关联、可导航"的结构，是后续按图生成内容的基础。

---

## 三、步骤 2：知识条目化与图谱化

### 2.1 条目化
把每篇文档拆成可独立引用的事实条目/知识点，标注三类属性：
- **内容**：事实、概念、关联、数据；
- **来源**：来自哪个文档、哪个版本；
- **层级/关联**：归属哪个主题，与哪些条目相关。

### 2.2 图谱化
在平台中形成知识图谱（节点=条目，边=关联）。用途：
- 供给"按图创作"（内容生产用图谱抽取素材并追溯）；
- 帮助识别**知识空白**与**冗余/冲突**。

### 2.3 知识空白识别
对照关键词语义地图与诊断覆盖缺口，列出"应该沉淀但还没有"的知识点，安排补齐。

---

## 四、步骤 3：来源、版本与一致性规范

### 3.1 来源追溯（三要素）
每个知识条目保持「事实-出处-版本」：
- 事实可被引用时能**反查到来源文档**；
- 版本可查，知道"这条信息是哪个版本定的、何时更新的"。

### 3.2 单一事实源（Single Source of Truth）
- 同名事实只在一处维护（以底座为准），内容生产与官网都以它为准，不各写各的；
- 建立变更历史，防止随意改动导致口径漂移。

### 3.3 与术语表对齐
- 将分册02 的品牌术语表纳入底座作为约束输入；
- 定期一致性审计：同名事实不同表述、同名术语混用需纠偏。

---

## 五、步骤 4：内外分权与安全

- 公开底座：白皮书摘要、公开 FAQ、对外口径，供生成引擎抓取与引用。
- 内部全量：含敏感、客户资料，分层授权，仅内部访问。
- 涉密：不进公开底座，服务端强制鉴权。
- 定期健康度审计：陈旧、过期条目标记下架，避免"老信息被引用"。

---

## 六、入库后的自动化提取说明

- 平台会自动完成**提取 + 去重 + 关联**，Agent 无需手动触发；
- 创建/导入文档时通过设置项决定该文档**是否进入知识底座**（对应"是否新知识"的判断）；
- 入库后通常需 1–3 分钟后台处理，不要立即搜索期误判为空；
- 衍生内容（基于底座生成的报告/总结）应设置为**不入底座**，避免算力浪费。

---

## 七、操作检查清单

- [ ] 家底盘点：散落资料全部归位到文档树
- [ ] 已判断每件内容"入/不入底座"
- [ ] 文档树结构稳定、可导航
- [ ] 知识条目具备「事实-出处-版本」三要素
- [ ] 知识图谱已建立，可识别空白与冲突
- [ ] 单一事实源 + 术语表对齐
- [ ] 内外分权、涉密隔离
- [ ] 健康度审计机制建立（定期更新/下架）
